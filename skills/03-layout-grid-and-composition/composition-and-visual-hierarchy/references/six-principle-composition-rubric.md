# Six-Principle Composition Rubric

Parent skill: [`../SKILL.md`](../SKILL.md) (`composition-and-visual-hierarchy`).

**When to read:** in design reviews, client critiques and internal QA of a page, spread, slide or
advertisement, when feedback needs shared vocabulary instead of taste. Source: McNeil (2010)
*The Web Designer's Idea Book, Volume 2*, HOW Books, which applies the six principles from Lisa
Graham's *Basics of Design*; layout QA items from Adams et al. (2012) *Graphic Design Rules*,
Frances Lincoln.

Score each principle 1-5 and cite observable evidence for the score.

| Principle | Test | Common failure |
|---|---|---|
| Emphasis | Before showing the design, ask the client to rank the page elements by importance. Compare with the design's visual ranking. One dominant message | Everything emphasised, so nothing stands out; accidental hierarchy |
| Contrast | Identify the single most contrasting element. Is it the main action? Density may rise lower down as interest rises | The call to action blends in; contrast spent on decoration |
| Balance | Squint. Does any side feel heavy enough to tip? Symmetry for formality, asymmetry for energy | Lopsided pages; forced symmetry on content that does not suit it |
| Alignment | Draw the grid lines on a screenshot. List every deliberate break and its reason | Alignment lost when the design becomes code |
| Repetition | List the page formulas (title and subtitle pairs, card anatomy, padding). Are they consistent across templates? | Every page designed from a blank slate |
| Flow | Trace the eye path: it should loop through every key option; navigation must not compete with the main message | "Pinball" pages; right-aligned layouts for left-to-right readers |

## Layout QA additions

- A single focal point; in left-to-right reading the top left is the natural entry, so starting
  elsewhere needs colour, size or a strong graphic.
- Scale contrast made extreme where drama is wanted; everything the same size is static.
- No white space trapped in the middle of a layout, enclosed on all sides.
- A hangline for columns of unequal length.
- Margins derived from a proportion (for example a wider outer and deeper foot margin), never
  software defaults.
- On long documents, bottom margin set so the last baseline sits on it; captions hang from their
  first line or use a proportional caption grid.
- Positions and sizes at round values; spacing set by rule and styles, not by eye.
- Design spreads, not single pages; at least one folio per spread.
- Thumbnail and above-the-fold tests for covers, packs and first screens.
- Take off the last accessory added.
