# Direction-Board Protocol

Parent skill: [`../SKILL.md`](../SKILL.md) (`art-direction-routes`).

**When to read:** when building and presenting direction boards, when a route departs from
familiar layout, when references are gathered, and when someone asks for a mood board.

---

## 1. The two dials and theme intensity

- **Style dial** - how much and how ordered: superclean, minimal, editorial, dense, expressive.
  A style does not prescribe imagery.
- **Theme or material dial** - which imagery world: fabric, soil and harvest, water, space,
  heritage print, illustration world. A theme prescribes a visual vocabulary.
- **Theme intensity** - how far the theme reaches:
  1. **Subtle / supporting** - a hint of the theme on a clean structure (one hero image, one
     material accent);
  2. **Styled conventional** - the theme styles familiar components; layout stays conventional;
  3. **Immersive / invented** - the theme becomes the interface itself.
- **Rule:** the more task-critical the product, the lower the intensity. Prefer the lightest
  level that still makes the work memorable. A theme with a **double meaning** (the brand name or
  mission and the imagery world at once) earns more intensity than a decorative one.

Showing the same theme at three intensities is a quick way for a client to agree how bold to be.

## 2. Direction board contents (one A3 page or one slide per route)

| Block | Content |
|---|---|
| Route name and lineage | For example "R1 Superclean Authority" and where the principles came from |
| Style thesis | "For [audience] doing [job], [route] signals [belief] because [reason]; it avoids [misfit]." |
| Dials | Style, theme, intensity, with a one-line reason each |
| Type character | Voice and roles; named faces chosen through `font-selection-and-pairing`, never banned faces |
| Palette logic | Anchor, temperature, accent role, contrast pre-check (route to `color-selection`) |
| Imagery rule | Photography or illustration brief in one sentence; local shoot; rights |
| Hero mock | The client's real headline and one real photograph or product |
| Component sample | One button, card or form row in the route's style |
| Mobile view | The first screen on a mid-range phone, including the main mobile task |
| Cost tiers | Build and maintain, with who can edit what without a designer |
| Weight note | Image and font weight for the hero on mobile (see `performance-as-ux-and-core-web-vitals`) |
| Risks and mitigations | Two or three, stated plainly |
| Borrow map | Which principle came from which reference, and how it was changed |

## 3. Borrow map (inspiration without copying)

1. Gather at least three references per element type (header, navigation, hero, content
   module, footer). Include at least one strong regional reference, so the direction does not
   import only Western cues.
2. For each reference write one line: "Useful because it solves [problem] by [technique]."
3. Map each technique to an element of the wireframe.
4. Unify with one type system, one colour logic and one spacing scale.
5. Run the replica check: the result must not look like any single source.

Present the borrow map to the client. It shows craft and pre-empts "you copied X" objections.

## 4. Unusual-layout test

Unusual layouts succeed when they:
- keep familiar anchors (logo placement, main navigation) and surprise only in the content
  region, or
- keep navigation changes small even when content styling is radical, or
- grow from the content itself (a map for location-led choices, tiles for many similar items).

Gate questions before an unusual route goes to the client:
1. Does the structure serve the site's purpose or the designer's wish to be noticed?
2. Which familiar anchors stay intact?
3. Can a first-time visitor find the way without instructions?
4. Is there a small-screen fallback (a different mobile interface is acceptable)?
5. Is checkout, payment or any form left conventional? It must be.

## 5. Content-driven structures (choose only when the content calls for them)

| Structure | Fits | Rules |
|---|---|---|
| One page | Lean content: portfolio, small agency, single product | Treat as a poster read in order; keep payload light |
| One-page sales pitch | One conversion (download, ticket, course) | Product explained in about ten words at the top; each section answers one objection; the same primary action in every section |
| Map-led | Location is a top decision factor (property, tourism, branch finders) | Map as the main interface with filters beside it; landmark directions and WhatsApp for East African users |
| Tiled grid | Many similar items | Equal tiles unless hierarchy needs variety; strong titles; filters kept consistent; list-view fallback; data budget |
| Full-viewport story | Immersive brand or venue experience | Content scales to fill the screen; test navigation hard; static fallback |

## 6. Mood-board policy

Two respected positions conflict. Adams and colleagues (*Graphic Design Rules*) discourage mood
boards as client deliverables: they are research tools, and clients should know their own brand.
Landa (*Strategic Creativity*) reports practitioners who agree a mood board early to set the
brand's "taste level" (for example elegant or brash) so personal taste stops driving feedback.

The engine reconciles them:
1. A mood board may be used **early and once** to agree the brand's taste level, from the
   brand's positioning, not from anyone's personal preference.
2. It contains colour temperature, type character, photographic mood and material, drawn from
   several sources with the borrow-map discipline.
3. It is **never** billed or presented as a concept, never replaces direction boards built from
   real content, and is never the basis for approving a route.
4. After the taste level is agreed, the mood board is archived and direction boards take over.

## 7. Presenting routes

- Agree the decision criteria first (for example: on brand, stands out in the category,
  timeless, practical across touchpoints, energises staff and customers).
- Open with the assignment and what was learned; then show the routes; end with next steps.
- Useful lines (adapt, do not recite):
  - "Three directions, one question: what should your buyer believe in the first five seconds?"
  - "All three are built from your real content, so you are judging reality, not a mood board."
  - "Each shows what it costs to build and what it costs to keep up."
  - "Here is where each idea came from and how we changed it for you."
- Do not decide in the room if the client wants time. Offer a short follow-up to discuss what
  each route is really doing, then decide against the criteria.
- Record the decision, the rejected routes and the reasons.
