# Game Interface Method

Return to [the parent skill](../SKILL.md).

## Information classes

Classify each item as immediate threat/opportunity, continuous player state, short-lived feedback, current objective/context, learnable world convention, or optional reference. Record refresh rate, consequence of delay, persistence, access alternative, source of truth and failure state.

## Presentation choices

| Choice | Use when | Required fallback |
|---|---|---|
| World-only | The cue is stable, learnable and reliably perceivable under pressure | Optional explicit cue for access or recovery |
| Diegetic/spatial | The world object can carry meaning without camera or contrast failure | Non-diegetic equivalent when occluded or inaccessible |
| Contextual | Information matters only near an object, choice or threshold | Predictable trigger and retained critical state |
| Persistent HUD | Delay or recall would cause unfair failure | Clutter and burn-in mitigation where applicable |
| Menu/reference | Comparison, planning or configuration needs time | Pause/authority rules and safe return to play |

## Required states

Cover first run, calm, traversal, high intensity, dialogue/cutscene, tutorial, map/inventory, pause/settings, save/load, offline, loading, empty, error, failure, success, account/consent, commercial surface, controller disconnect/reconnect, input swap, localisation expansion, reduced motion, high contrast, captions and assistive alternatives.

## Validation

Use representative tasks and measure comprehension, time to relevant information, input/focus errors, accidental activation, recovery and stopping. Record device, distance, build, content/locale, assist settings and failures. A static frame does not prove play-state readability.
