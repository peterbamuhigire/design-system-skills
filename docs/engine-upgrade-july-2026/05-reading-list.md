# Recommended Books and Reading Material

## Must Encode Now

| Title | Author/issuer | Gap filled |
| --- | --- | --- |
| Material Design 3 Guidelines | Google | Modern component, motion, colour, and adaptive design baseline. |
| Apple Human Interface Guidelines | Apple | Platform-native iOS, iPadOS, macOS, and accessibility expectations. |
| WCAG 2.2 | W3C WAI | Current accessibility success criteria and conformance language. |
| Designing Interfaces, 3rd ed. | Jenifer Tidwell, Charles Brewer, Aynne Valencia | Interaction pattern vocabulary and practical examples. |
| Refactoring UI | Adam Wathan and Steve Schoger | Practical visual polish patterns for product interfaces. |
