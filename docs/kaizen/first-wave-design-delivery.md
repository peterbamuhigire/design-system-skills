# First-wave design delivery fixture

Status: IMPLEMENTED FIXTURE SPECIFICATION, not a completed client artefact. Date: 7 September 2026.

The fixture operationalises D01–D04. It requires a labelled brief, audience/task thesis, exact font and image files or explicit fictional labels, target surfaces, token source, component state matrix, rendered baseline, reopened output, owner and approver.

## Review sequence

1. Record the authored type, palette and hierarchy choice and its task fit.
2. Capture normal, long-copy, missing-asset, empty, error, focus and reduced-motion states.
3. Map each component state to token, content, interaction and implementation owner.
4. Compare source and rendered output and log every variance.
5. Blind-review baseline and improved variants using `skills/00-cross-cutting-ops-qa-a11y/visual-product-slop-audit/references/visual-tells-checklist.md`.

Any missing render, unverified licence, undocumented variance or context-wrong polish is `NOT_ASSESSED` or rejected. This fixture does not claim visual quality, accessibility or stakeholder acceptance.
